# C and C++ Clang Template Project

A simple Clang, CMake and Ninja template project for C and C++.

## Setup

- **Clang** 23 or newer
- **CMake** 4.5.0 or newer
- **Ninja** 1.13 or newer

## Building From Source

```powershell
# Debug
cmake --preset debug
cmake --build --preset debug

# Release
cmake --preset release
cmake --build --preset release
```
